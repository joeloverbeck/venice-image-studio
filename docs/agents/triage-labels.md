# Triage labels

Use these label strings whenever an engineering skill names a canonical role.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation. |
| `needs-info` | `needs-info` | Needs additional information. |
| `ready-for-agent` | `ready-for-agent` | Specified for agent execution once the owner activates the bounded work. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

Readiness and activation follow `docs/foundation/05-delivery-and-acceptance.md`
and the constitution. A label alone authorizes neither implementation nor
unattended continuation, paid calls or publication.

Edit the tracker-label column if the repository adopts different names.
